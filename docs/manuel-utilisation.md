# Manuel d'utilisation

## Présentation

Cette application permet de présenter les menus de Vite & Gourmand, de créer un compte utilisateur et de passer des commandes.

## Identifiants de démonstration

- Administrateur : admin@example.com / admin123!
- Employé : employe@example.com / employe123!
- Utilisateur : user@example.com / user123!

## Parcours principaux

1. Consultation des menus sur la page d'accueil.
2. Recherche et filtrage des menus.
3. Création d'un compte utilisateur.
4. Passage d'une commande.
5. Consultation de l'espace utilisateur.
6. Gestion des commandes depuis l'espace employé.
7. Consultation des statistiques depuis l'espace administrateur.
