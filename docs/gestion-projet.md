# Documentation de gestion de projet

## Méthodologie

Le projet a été organisé autour d'une démarche progressive :

1. Analyse des besoins
2. Maquettage et structure du projet
3. Développement du back-end et du front-end
4. Intégration des bases de données relationnelle et NoSQL
5. Tests fonctionnels et sécurisation
6. Déploiement et documentation

## Outils envisagés

- Trello, Notion ou Jira pour le suivi des tâches
- Git avec branches principales et branches de fonctionnalité

## Bonnes pratiques

- Commits clairs et réguliers
- Branche principale pour la version stable
- Branche de développement pour l'intégration
- Développement par fonctionnalité
