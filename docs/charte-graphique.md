# Charte graphique

## Palette de couleurs

La charte graphique actuelle utilisée par l’interface correspond aux couleurs définies dans le fichier CSS du projet :

- Vert sauge : #7baf8b
- Vert foncé : #4f7f5f
- Beige clair : #f4efe6
- Jaune clair : #fdf9e3
- Blanc : #ffffff
- Gris chaud : #6f6f6f
- Gris clair : #e6e6e6
- Orange : #e8a15b
- Rouge : #d96c6c

## Typographies

- Titres : Montserrat, sans-serif
- Corps de texte : Open Sans, sans-serif
- Style décoratif éventuel : Italianno, cursive

## Principes visuels

- Style sobre, chaleureux et naturel
- Contraste suffisant pour une lecture accessible
- Interface claire pour la navigation sur mobile et bureau
- Utilisation de couleurs apaisantes pour renforcer l’identité du restaurant

## Usage attendu

- Les titres principaux et les boutons utilisent la typographie Montserrat.
- Les paragraphes et textes standards utilisent Open Sans.
- Les couleurs vertes et beiges structurent visuellement l’interface et mettent en valeur les éléments importants.
